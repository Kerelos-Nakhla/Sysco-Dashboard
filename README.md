# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview

The **Sales Performance Dashboard** is an interactive Business Intelligence solution built with **Microsoft Power BI** to analyze sales performance from multiple business perspectives.

---

## 🎯 Business Problem

Organizations generate large volumes of sales data, but making informed decisions requires more than raw numbers. This dashboard transforms raw sales data into meaningful business insights for decision-makers.

---

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Snowflake Schema
- Time Intelligence
- Data Modeling

---

## 📈 Dashboard Pages

### 📍 Sales Performance

- Total Sales
- Total Freight
- Orders
- YoY Growth
- Average Ship Days
- Sales by Year
- Sales by Country
- Shipping Analysis

### 📍 Product Performance

- Product Categories
- Top 5 Products
- Bottom 5 Products
- Reorder Analysis
- Active vs Inactive Products

### 📍 Customer, Employee & Supplier

- Customer Analysis
- Employee Performance
- Supplier Performance
